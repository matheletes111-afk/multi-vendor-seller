1. API OVERVIEW (TOTAL 10 DOCUMENTS)
--------------------------------------------------------------------------------
NOTE FOR MOBILE DEVELOPERS: ZERO CODE CHANGES REQUIRED!
The backend automatically injects the live Admin-configured 4-tier category base
commission rates and fallback guarantees directly into the existing `content` (HTML)
and `rawText` (plain text) fields. Your existing WebViews and HtmlWidgets will
instantly display the updated, dynamic terms and conditions out-of-the-box.

All 10 legal and policy documents (2 from website footer + 8 from `terms/` folder)
are available through dedicated endpoints and through a universal dynamic endpoint:

  - Universal Endpoint: GET /mobileapi/legal/[slug]
  - Document Catalog List: GET /mobileapi/legal/list

Base URL: https://yourdomain.com  (replace with actual backend domain)

All endpoints return JSON. The `content` field contains rendered HTML safe to
display via a WebView or HtmlWidget. The `rawText` field is plain text fallback.

HTTP 404 (unknown slug):
{
  "success": false,

IMPORTANT:
- Always check `response['success'] == true` before reading `content`.
- Use `rawText` as a plain-text fallback if HTML rendering fails.
- The `baseCommissions` field contains the live Admin-configured percentage rates for all 4 seller verticals.

const String kBaseUrl = "https://yourdomain.com";

// ============================================================
// 1. DATA MODEL
// ============================================================
class LegalDocument {
  final bool success;
  final String id;
  final String slug;
  final String title;
  final String source;
  final String lastUpdated;
  final String content;   // HTML string — render via HtmlWidget
  final String rawText;   // Plain text fallback

  LegalDocument({
    required this.success,
    required this.id,
    required this.slug,
    required this.title,
    required this.source,
    required this.lastUpdated,
    required this.content,
    required this.rawText,
  });

  factory LegalDocument.fromJson(Map<String, dynamic> json) {
    return LegalDocument(
      success: json['success'] ?? false,
      id: json['id'] ?? '',
      slug: json['slug'] ?? '',
      title: json['title'] ?? '',
      source: json['source'] ?? '',
      lastUpdated: json['lastUpdated'] ?? '',
      content: json['content'] ?? '',
      rawText: json['rawText'] ?? '',
    );
  }
}

// ============================================================
// 2. API SERVICE
// ============================================================
class LegalApiService {
  /// Fetch a single legal document by its API endpoint path.
  /// [endpointPath] example: "/mobileapi/legal/vendor-agreement"
  static Future<LegalDocument> fetchDocument(String endpointPath) async {
    final uri = Uri.parse('$kBaseUrl$endpointPath');
    final res = await http.get(uri, headers: {'Accept': 'application/json'});

    if (res.statusCode == 200) {
      final decoded = json.decode(res.body) as Map<String, dynamic>;
      if (decoded['success'] == true) {
        return LegalDocument.fromJson(decoded);
      }
      throw Exception(decoded['error'] ?? 'Document not found');
    } else if (res.statusCode == 404) {
      throw Exception('Document not found (404)');
    } else {
      throw Exception('Server error: ${res.statusCode}');
    }
  }
}

class _LegalDocBottomSheetState extends State<_LegalDocBottomSheet> {
  LegalDocument? document;
  bool isLoading = true;
  String? error;

  @override
  void initState() {
    super.initState();
    _fetchDoc();
  }

  Future<void> _fetchDoc() async {
    try {
      final doc = await LegalApiService.fetchDocument(widget.endpointPath);
      if (mounted) {
        setState(() {
          document = doc;
          isLoading = false;
        });
      }
    } catch (e) {
      if (mounted) {
        setState(() {
          error = e.toString();
          isLoading = false;
        });
      }
    }
  }

  void _handleAgree() {
    widget.onAgree();
    Navigator.of(context).pop();
  }

  @override
  Widget build(BuildContext context) {
    final screenHeight = MediaQuery.of(context).size.height;
    return Container(
      height: screenHeight * 0.88,
      decoration: const BoxDecoration(
        color: Colors.white,
        borderRadius: BorderRadius.vertical(top: Radius.circular(24)),
      ),
      child: Column(
        children: [
          // ─── Drag Handle ─────────────────────────────────────────────
          const SizedBox(height: 12),
          Container(
            width: 40, height: 4,
            decoration: BoxDecoration(
              color: Colors.grey.shade300,
              borderRadius: BorderRadius.circular(2),
            ),
          ),
          const SizedBox(height: 4),

          // ─── Header ──────────────────────────────────────────────────
          Padding(
            padding: const EdgeInsets.symmetric(horizontal: 20, vertical: 12),
            child: Row(
              children: [
                const Icon(Icons.description_outlined, color: Color(0xFF7C3AED), size: 22),
                const SizedBox(width: 10),
                Expanded(
                  child: Text(
                    document?.title ?? widget.title,
                    style: const TextStyle(
                      fontSize: 15,
                      fontWeight: FontWeight.bold,
                      color: Color(0xFF0F172A),
                    ),
                    maxLines: 2,
                    overflow: TextOverflow.ellipsis,
                  ),
                ),
                IconButton(
                  icon: const Icon(Icons.close, size: 20),
                  onPressed: () => Navigator.of(context).pop(),
                ),
              ],
            ),
          ),

          // ─── Source & date subtitle ───────────────────────────────────
          if (document != null)
            Padding(
              padding: const EdgeInsets.fromLTRB(20, 0, 20, 8),
              child: Row(
                children: [
                  Text(
                    'Updated: ${document!.lastUpdated}',
                    style: const TextStyle(fontSize: 11, color: Color(0xFF94A3B8)),
                  ),
                ],
              ),
            ),

          const Divider(height: 1),

          // ─── Body ────────────────────────────────────────────────────
          Expanded(
            child: Builder(builder: (_) {
              if (isLoading) {
                return const Center(
                  child: CircularProgressIndicator(color: Color(0xFF7C3AED)),
                );
              }
              if (error != null) {
                return Center(
                  child: Padding(
                    padding: const EdgeInsets.all(24),
                    child: Column(
                      mainAxisSize: MainAxisSize.min,
                      children: [
                        const Icon(Icons.error_outline, color: Colors.red, size: 40),
                        const SizedBox(height: 12),
                        Text(
                          'Failed to load document.\n$error',
                          textAlign: TextAlign.center,
                          style: const TextStyle(color: Colors.red, fontSize: 13),
                        ),
                        const SizedBox(height: 16),

                          onPressed: () {
                            setState(() { isLoading = true; error = null; });
                            _fetchDoc();
                          },
                          child: const Text('Retry'),
                        ),
                      ],
                    ),
                  ),
                );
              }
              // Render HTML content
              return SingleChildScrollView(
                padding: const EdgeInsets.symmetric(horizontal: 20, vertical: 16),

                color: Colors.grey.shade50,

                children: [

                    child: OutlinedButton(
                      onPressed: () => Navigator.of(context).pop(),
                      style: OutlinedButton.styleFrom(
                        shape: RoundedRectangleBorder(
                          borderRadius: BorderRadius.circular(12),
                        ),
                        padding: const EdgeInsets.symmetric(vertical: 14),

                      child: const Text('Close'),
                    ),
                  ),
                  const SizedBox(width: 12),
                  Expanded(
                    flex: 2,

            child: TextButton.icon(
              onPressed: () {
                showLegalDocModal(
                  context: context,
                  title: title,
                  endpointPath: endpointPath,
                  isAgreed: isChecked,
                  onAgree: onModalAgree,
                );
              },
              icon: const Icon(Icons.open_in_new_rounded, size: 15),
              label: Text(
                isChecked ? 'Review Document' : 'Read & Agree',
                style: const TextStyle(fontSize: 12, fontWeight: FontWeight.w600),
              ),
              style: TextButton.styleFrom(
                foregroundColor: isChecked
                    ? const Color(0xFF059669)
                    : const Color(0xFF7C3AED),
                padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 6),
                tapTargetSize: MaterialTapTargetSize.shrinkWrap,
              ),
            ),
          ),
        ],
      ),
    );
  }

  Future<void> _submit() async {
    if (!allAgreed) return;
    setState(() => isSubmitting = true);

    final payload = {
      "step": 6,
      "data": {
        "agreedToTerms": agreedToTerms,
        "agreedToPrivacy": agreedToPrivacy,
        "agreedToReturnPolicy": agreedToReturnPolicy,
        "agreedToCommission": agreedToCommission,
        "hearAboutUs": hearAboutUs,
      }
    };

    try {
      widget.onSubmit(payload);
      // Navigation to next step / success page is handled by parent
    } catch (e) {
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text('Submission failed: $e'), backgroundColor: Colors.red),
        );
      }
    } finally {
      if (mounted) setState(() => isSubmitting = false);
    }
  }
}

NOTES FOR MOBILE DEVELOPER
================================================================================

1. PACKAGE SETUP — add to pubspec.yaml:
   dependencies:
     http: ^1.2.0
     flutter_widget_from_html: ^0.15.0  # renders the HTML `content` field

2. BASE URL — change `kBaseUrl` constant to actual production domain.

3. onSubmit CALLBACK — `SellerAgreementStepScreen` does NOT call the backend
   itself. It calls `widget.onSubmit(payload)` with the agreement data.
   The parent screen/wizard is responsible for the actual HTTP POST to the
   seller onboarding API and navigating to Step 7 (success/pending screen).

4. SELLER TYPES — the same screen works for Product, Service, Restaurant and
   Hotel sellers. Pass `sellerType` so the parent can route to the correct
   backend endpoint:
     - Product:    POST /api/product-seller/onboarding
     - Service:    POST /api/service-seller/onboarding
     - Restaurant: POST /api/restaurant-seller/onboarding
     - Hotel:      POST /api/hotel-seller/onboarding

5. ALREADY-AGREED STATE — if the seller navigates back to Step 6 and had
   already agreed to some items, load their saved values from your local
   state manager and pre-populate the 4 booleans before building the screen.

6. INTERNET CHECK — wrap `_fetchDoc()` with a connectivity check and show a
   user-friendly offline message if needed.

7. SAFE HTML — the `content` field is server-generated HTML from official docx
   files. It is safe to render, but consider using `flutter_widget_from_html`
   with the `factoryBuilder` option if you need to disable links inside docs.
