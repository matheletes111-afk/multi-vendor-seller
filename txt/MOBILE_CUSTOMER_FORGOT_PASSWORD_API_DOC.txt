================================================================================
CUSTOMER MOBILE APP - FORGOT PASSWORD & RESET PASSWORD API DOCUMENTATION
================================================================================

1. FLOW OVERVIEW
--------------------------------------------------------------------------------
1. User clicks "Forgot Password" on the Customer Mobile App Login screen.
2. User enters their registered Email or Phone number.
3. Mobile App calls:
   POST /mobileapi/customer/auth/forgot-password/send-otp
4. Server generates a 6-digit OTP code (valid for 10 minutes):
   - SMS is dispatched instantly (without link, arrives in 1-2 seconds).
   - Email is dispatched with the OTP code and direct reset instructions.
5. Server returns HTTP 200 with resendCooldown: 60 (seconds) and expiresIn: 600.
6. Mobile App opens the OTP & New Password screen:
   - Displays a 60-second countdown for the "Resend OTP" button.
   - User enters: 6-digit OTP, New Password, Confirm New Password.
7. Mobile App calls:
   POST /mobileapi/customer/auth/forgot-password/reset
8. Server verifies OTP and updates password. Returns HTTP 200 on success.
9. Mobile App shows success toast and redirects user to Login screen.


================================================================================
2. API ENDPOINTS
================================================================================
Base URL: https://your-domain.com (or local dev URL)

1. Send / Resend OTP:
   POST /mobileapi/customer/auth/forgot-password/send-otp

2. Verify OTP & Reset Password:
   POST /mobileapi/customer/auth/forgot-password/reset


================================================================================
3. DETAILED API SPECIFICATIONS
================================================================================

--------------------------------------------------------------------------------
STEP 1: SEND OTP (FORGOT PASSWORD INITIATION)
--------------------------------------------------------------------------------
URL: /mobileapi/customer/auth/forgot-password/send-otp
Method: POST
Headers:
  Content-Type: application/json

Request Body Option A (Recommended - single input field):
{
  "identifier": "customer@example.com"    // OR mobile number: "+23276123456" or "076123456"
}

Request Body Option B (Explicit email):
{
  "email": "customer@example.com"
}

Request Body Option C (Explicit phone):
{
  "phone": "076123456",
  "phoneCountryCode": "+232"             // Optional, defaults to +232
}

[SUCCESS RESPONSE - HTTP 200 OK]
{
  "success": true,
  "message": "If an account exists with this credential, OTP has been sent.",
  "data": {
    "email": "customer@example.com",
    "phone": "+23276123456",
    "expiresIn": 600,                    // OTP valid for 600 seconds (10 minutes)
    "resendCooldown": 60                 // Resend button cooldown: 60 seconds
  }
}

[COOLDOWN ERROR RESPONSE - HTTP 429 Too Many Requests]
{
  "success": false,
  "error": "Please wait 45 seconds before requesting a new OTP",
  "waitTime": 45                         // Seconds remaining before next resend
}

[VALIDATION ERROR - HTTP 400 Bad Request]
{
  "success": false,
  "error": "Email or mobile number is required"
}


--------------------------------------------------------------------------------
STEP 2: RESET PASSWORD (VERIFY OTP & SET NEW PASSWORD)
--------------------------------------------------------------------------------
URL: /mobileapi/customer/auth/forgot-password/reset
Method: POST
Headers:
  Content-Type: application/json

Request Body:
{
  "identifier": "customer@example.com",  // OR email / phone used in Step 1
  "otp": "123456",                       // 6-digit numeric OTP
  "newPassword": "newPassword@123"       // Minimum 6 characters
}

Or with separate fields:
{
  "email": "customer@example.com",       // OR "phone": "076123456"
  "otp": "123456",
  "newPassword": "newPassword@123"
}

[SUCCESS RESPONSE - HTTP 200 OK]
{
  "success": true,
  "message": "Password reset successful.",
  "data": {
    "loginUrl": "/customer/login?reset=1"
  }
}

[INVALID OTP / CREDENTIALS - HTTP 400 Bad Request]
{
  "success": false,
  "error": "Invalid credentials or OTP."
}

[EXPIRED OTP - HTTP 400 Bad Request]
{
  "success": false,
  "error": "Invalid credentials or OTP.",
  "expired": true
}

[VALIDATION ERROR - HTTP 400 Bad Request]
{
  "success": false,
  "error": "Password must be at least 6 characters long"
}

[RATE LIMIT EXCEEDED - HTTP 429 Too Many Requests]
{
  "success": false,
  "error": "Too many failed attempts. Try again in 15 minute(s)."
}

4. MOBILE APP IMPLEMENTATION CHECKLIST FOR DEVELOPERS
================================================================================
1. [Screen 1: Forgot Password]:
   - Input: Single text field for Email or Mobile Number.
   - Button: "Send OTP".
   - When clicked, call /send-otp. On HTTP 200, navigate to Screen 2.

2. [Screen 2: Reset Password]:
   - Input 1: 6-digit OTP box (numeric keypad, autofocus, maxLength=6).
   - Input 2: New Password (with eye icon to show/hide).
   - Input 3: Confirm New Password (validate client-side that passwords match).
   - "Resend OTP" button: Start 60-second countdown timer from data.resendCooldown.
     Disable button until timer reaches 0. Clicking it calls /send-otp again.
   - Button: "Reset Password".
   - When clicked, call /reset. On HTTP 200, show success message and navigate to Login screen.
