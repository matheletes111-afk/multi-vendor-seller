1. HIGH-LEVEL ARCHITECTURE FOR SELLERS
================================================================================
All four seller types on Meeem can use the Float Card Payment Gateway for:
1. Subscriptions: Purchasing or renewing monthly / annual seller membership plans
   or queuing upcoming packs with discount coupon support.
2. Seller Ads: Creating sponsored campaigns or paying for pending ads.
3. Order & Booking Audit Trail: Reviewing complete buyer payment identifiers
   (`flotOrderId`, `flotPaymentLink`, `paymentMethod`, `paymentStatus`, `paidAt`)
   alongside seller net earnings, commission rates, and escrow settlement status.

2.1. PAY FLOAT FOR SUBSCRIPTION PLAN (INITIATION)
--------------------------------------------------------------------------------
Endpoints Available (Both module-specific and universal routes are supported):
- Product Seller   : POST /mobileapi/product-seller/subscription/pay-float
- Service Seller   : POST /mobileapi/service-seller/subscription/pay-float
- Hotel Seller     : POST /mobileapi/hotel-seller/subscription/pay-float
- Restaurant Seller: POST /mobileapi/restaurant-seller/subscription/pay-float
- Universal Seller : POST /mobileapi/seller/subscription/pay-float

Auth   : Bearer <seller_token>
Headers: Content-Type: application/json

Request Body:
{
  "planId": "plan_uuid_4455",
  "couponCode": "SELLERDISCOUNT20" // Optional
}

Case A - Standard Paid Subscription Response (200 OK):
{
  "success": true,
  "purchaseId": "sub_purchase_uuid_9988",
  "payableAmount": 80.00,
  "planName": "Product Seller Premium Plan",
  "paymentUrl": "https://flot.pay.me/checkout/session/flot_sub_chk_9988aabbcc",
  "flotOrderId": "PROD_sub_purchase_uuid_9988_1731321000000",
  "message": "Float checkout link generated successfully"
}
* Mobile Action: Open `paymentUrl` in an in-app browser or Webview, and initiate
  polling to the verify endpoint using the returned `purchaseId`.

Case B - 100% Free Coupon Applied (Activated / Queued instantly without checkout):
{
  "success": true,
  "purchaseId": "sub_purchase_uuid_9988",
  "status": "ACTIVE", // or "QUEUED" if seller has an active pack running
  "payableAmount": 0,
  "planName": "Product Seller Premium Plan",
  "message": "100% coupon applied! Your plan is activated successfully."
}

2.2. VERIFY SUBSCRIPTION PAYMENT STATUS (POLLING)
--------------------------------------------------------------------------------
Endpoints Available:
- Module-Specific: GET /mobileapi/{product-seller|service-seller|hotel-seller|restaurant-seller}/subscription/verify-payment?purchaseId={purchaseId}
- Universal      : GET /mobileapi/seller/subscription/verify-payment?purchaseId={purchaseId}
Auth: Bearer <seller_token>

Case A - Payment Confirmed (Gateway 3DS completed):
{
  "success": true,
  "paid": true,
  "status": "ACTIVE", // or "QUEUED" if an active plan was already running
  "paymentMethod": "FLOAT",
  "flotOrderId": "PROD_sub_purchase_uuid_9988_1731321000000",
  "paidAt": "2026-11-11T10:45:00.000Z"
}
* Mobile Action: Close Webview, show "Subscription Activated" banner, and refresh
  seller dashboard.

Case B - Pending (User currently on 3D Secure / OTP):
{
  "success": true,
  "paid": false,
  "status": "PENDING_PAYMENT",
  "message": "Payment is being processed by Float gateway. Please complete verification."
}

6. ERROR HANDLING & GATEWAY STATUS CODES REFERENCE
================================================================================
- 400 Bad Request          : Invalid payload, inactive plan, or missing parameters.
- 401 Unauthorized         : Missing or expired Bearer JWT token in Authorization header.
- 403 Forbidden            : Token belongs to an unauthorized seller module or another user.
- 404 Not Found            : Seller profile, plan, ad, or order not found.
- 502 Bad Gateway          : Float Gateway connection timeout or external API unreachable.
- 500 Internal Server Error: Database or unhandled server exception.
================================================================================
