================================================================================
ALL SELLERS MOBILE APP - FORGOT PASSWORD & RESET PASSWORD API DOCUMENTATION
(Product Seller, Service Seller, Restaurant Seller, Hotel Seller)
================================================================================

1. FLOW OVERVIEW
--------------------------------------------------------------------------------
This documentation applies to all 4 Seller sections on the Mobile App:
  1. Product Seller:    /mobileapi/product-seller/auth/forgot-password/...
  2. Service Seller:    /mobileapi/service-seller/auth/forgot-password/...
  3. Restaurant Seller: /mobileapi/restaurant-seller/auth/forgot-password/...
  4. Hotel Seller:      /mobileapi/hotel-seller/auth/forgot-password/...

Workflow:
1. Seller taps "Forgot Password?" on their respective Seller Login screen.
2. Seller enters their registered Email address or Mobile number.
3. Mobile App calls the send-otp endpoint for that seller role.
4. Server generates a 6-digit OTP code (valid for 10 minutes):
   - SMS is dispatched instantly to the seller's phone (clean transactional text, no link, delivers in 1-2 seconds).
   - Email is dispatched with the OTP code and instructions.
5. Server responds with HTTP 200 with resendCooldown: 60 (seconds) and expiresIn: 600.
6. Mobile App opens the Reset Password screen with a 60-second Resend countdown.
7. Seller enters: 6-digit OTP, New Password, Confirm New Password.
8. Mobile App calls the reset endpoint for that seller role.
9. Server verifies OTP and updates password. Returns HTTP 200 on success.
10. Mobile App shows success toast and redirects seller to Login screen.

2. API ENDPOINTS BY SELLER TYPE
================================================================================
Base URL: https://your-domain.com (or local dev URL)

A) PRODUCT SELLER:
   - Send / Resend OTP: POST /mobileapi/product-seller/auth/forgot-password/send-otp
   - Reset Password:    POST /mobileapi/product-seller/auth/forgot-password/reset

B) SERVICE SELLER:
   - Send / Resend OTP: POST /mobileapi/service-seller/auth/forgot-password/send-otp
   - Reset Password:    POST /mobileapi/service-seller/auth/forgot-password/reset

C) RESTAURANT SELLER:
   - Send / Resend OTP: POST /mobileapi/restaurant-seller/auth/forgot-password/send-otp
   - Reset Password:    POST /mobileapi/restaurant-seller/auth/forgot-password/reset

D) HOTEL SELLER:
   - Send / Resend OTP: POST /mobileapi/hotel-seller/auth/forgot-password/send-otp
   - Reset Password:    POST /mobileapi/hotel-seller/auth/forgot-password/reset


================================================================================
3. DETAILED API SPECIFICATIONS
================================================================================

--------------------------------------------------------------------------------
STEP 1: SEND OTP (FORGOT PASSWORD INITIATION)
--------------------------------------------------------------------------------
URL: /mobileapi/{seller-type}/auth/forgot-password/send-otp
Method: POST
Headers:
  Content-Type: application/json

Request Body Option A (Recommended - single input field):
{
  "identifier": "seller@example.com"     // OR mobile number: "+23276123456" or "076123456"
}

Request Body Option B (Explicit email):
{
  "email": "seller@example.com"
}

Request Body Option C (Explicit phone):
{
  "phone": "076123456",
  "phoneCountryCode": "+232"             // Optional
}

[SUCCESS RESPONSE - HTTP 200 OK]
{
  "success": true,
  "message": "If an account exists with this credential, OTP has been sent.",
  "data": {
    "email": "seller@example.com",
    "phone": "+23276123456",
    "expiresIn": 600,                    // 600 seconds = 10 minutes
    "resendCooldown": 60                 // 60 seconds countdown for Resend button
  }
}

[COOLDOWN ERROR RESPONSE - HTTP 429 Too Many Requests]
{
  "success": false,
  "error": "Please wait 48 seconds before requesting a new OTP",
  "waitTime": 48
}

[VALIDATION ERROR - HTTP 400 Bad Request]
{
  "success": false,
  "error": "Email or mobile number is required"
}


--------------------------------------------------------------------------------
STEP 2: RESET PASSWORD (VERIFY OTP & SET NEW PASSWORD)
--------------------------------------------------------------------------------
URL: /mobileapi/{seller-type}/auth/forgot-password/reset
Method: POST
Headers:
  Content-Type: application/json

Request Body:
{
  "identifier": "seller@example.com",    // OR email / phone used in Step 1
  "otp": "123456",                       // 6-digit numeric OTP
  "newPassword": "newSellerPassword123"  // Minimum 6 characters
}

Or with separate fields:
{
  "email": "seller@example.com",         // OR "phone": "076123456"
  "otp": "123456",
  "newPassword": "newSellerPassword123"
}

[SUCCESS RESPONSE - HTTP 200 OK]
{
  "success": true,
  "message": "Password reset successful.",
  "data": {
    "loginUrl": "/product-seller/login?reset=1"
  }
}

[INVALID OTP / CREDENTIALS - HTTP 400 Bad Request]
{
  "success": false,
  "error": "Invalid credentials or OTP."
}

[EXPIRED OTP - HTTP 400 Bad Request]
{
  "success": false,
  "error": "Invalid credentials or OTP.",
  "expired": true
}

[VALIDATION ERROR - HTTP 400 Bad Request]
{
  "success": false,
  "error": "Password must be at least 6 characters long"
}

[RATE LIMIT EXCEEDED - HTTP 429 Too Many Requests]
{
  "success": false,
  "error": "Too many failed attempts. Try again in 15 minute(s)."
}

4. MOBILE APP IMPLEMENTATION CHECKLIST FOR DEVELOPERS
================================================================================
1. Dynamic Endpoint Selection:
   - Determine which seller app/tab is active:
     const endpointPrefix = isRestaurant ? "restaurant-seller" : isHotel ? "hotel-seller" : isService ? "service-seller" : "product-seller";
   - Call `/mobileapi/${endpointPrefix}/auth/forgot-password/send-otp`
   - Call `/mobileapi/${endpointPrefix}/auth/forgot-password/reset`

2. UI Flow:
   - Screen 1: Email or Mobile number field -> "Send OTP" button.
   - Screen 2: 6-digit OTP input, New Password, Confirm New Password.
   - Resend OTP Button: Start 60-second timer from `data.resendCooldown`. Enable button when timer reaches 0.
   - On success: Navigate to Seller Login screen with a success banner/toast.
