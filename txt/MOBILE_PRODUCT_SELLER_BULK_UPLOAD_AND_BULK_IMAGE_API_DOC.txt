1. OVERVIEW & CAPABILITY STATUS
================================================================================
Does the mobile API have bulk product upload and bulk image upload support?
- PREVIOUS STATUS: No. Only the web seller dashboard supported bulk Excel/CSV
  imports and bulk image management, protected strictly with web session cookies.
  The `/mobileapi/product-seller/upload` directory was empty.
- CURRENT STATUS: YES, FULLY IMPLEMENTED AND SUPPORTED.
  Dedicated mobile endpoints have been built under `/mobileapi/product-seller/`
  with full Bearer JWT authentication, multi-variant grouping, auto-category
  matching, S3 storage with EXIF sanitization, and automated AI dimension
  enrichment.
  Additionally, existing `/api/product-seller/...` endpoints have been upgraded
  with dual authentication so mobile apps can call either path seamlessly.

PRIMARY ENDPOINTS:
  1. Bulk Image Upload:    POST   /mobileapi/product-seller/upload/bulk-images
  2. Image Gallery List:   GET    /mobileapi/product-seller/upload/bulk-images
  3. Delete Images:        DELETE /mobileapi/product-seller/upload/bulk-images
  4. Toggle Used Status:   PATCH  /mobileapi/product-seller/upload/bulk-images
  5. Download Template:    GET    /mobileapi/product-seller/product/bulk-template
  6. Bulk Product Import:  POST   /mobileapi/product-seller/product/bulk-import
  7. AI Packaging Progress: GET   /mobileapi/product-seller/product/bulk-import/progress

ALIAS COMPATIBILITY ENDPOINTS (Plural aliases also supported):
  - GET  /mobileapi/product-seller/products/bulk-template
  - POST /mobileapi/product-seller/products/bulk-import
  - GET  /mobileapi/product-seller/products/bulk-import/progress
  - POST /api/product-seller/products/bulk-import (supports Bearer JWT)
  - GET  /api/product-seller/products/bulk-template (supports Bearer JWT)
  - GET  /api/product-seller/products/bulk-import/progress (supports Bearer JWT)
  - POST /api/product-seller/upload/bulk-images (supports Bearer JWT)

FREQUENTLY ASKED QUESTIONS: EXCEL DOWNLOAD & CROSS-PLATFORM COMPATIBILITY
--------------------------------------------------------------------------------
Q1: Is the Excel template download available on Mobile?
A1: YES! The mobile API endpoint is:
    GET /mobileapi/product-seller/product/bulk-template?format=xlsx&dummy=true
    (or ?format=csv or ?format=json).
    The mobile app can download the template directly to the user's phone, open
    it with Microsoft Excel, Google Sheets, or Apple Numbers, or share it via
    WhatsApp / email.

Q2: Are the Excel templates COMMON between Web and Mobile?
A2: YES, 100% COMMON.
    - The backend uses the exact same template generator (`buildTemplateXlsx`)
      for both web and mobile.
    - Both contain the exact same 24 columns, headers, dummy rows, and instructions.
    - A template downloaded on Web can be uploaded from the Mobile App.
    - A template downloaded from the Mobile App can be uploaded on the Web.
    - Both use the same atomic database transaction, validation engine, category
      auto-matching, and AI dimensions background processor.

3.1 UPLOAD IMAGES IN BULK
--------------------------------------------------------------------------------
Uploads 1 or multiple image files to Amazon S3 (with fallback), strips EXIF
metadata for privacy/security, and registers each file into the seller's media
gallery library.

Endpoint: POST /mobileapi/product-seller/upload/bulk-images
Headers:
  Authorization: Bearer <TOKEN>
  Content-Type: multipart/form-data

Request Body (FormData):
  - `files`: File[] (multiple files)
  - OR `file`: File (single file)
  - Supported extensions: .jpg, .jpeg, .png, .webp, .gif
  - Max size per file: 10 MB

Success Response (200 OK):

5.1 UPLOAD & IMPORT SPREADSHEET
--------------------------------------------------------------------------------
Endpoint: POST /mobileapi/product-seller/product/bulk-import
(Alias:   POST /mobileapi/product-seller/products/bulk-import)
Headers:
  Authorization: Bearer <TOKEN>
  Content-Type: multipart/form-data

Request Body (FormData):
  - `file`: File (The .xlsx or .csv spreadsheet file)
  - Max file size: 8 MB
  - Max data rows: 500 rows per file

Success Response (200 OK):
{
  "success": true,
  "ok": true,
  "data": {
    "createdProducts": 10,
    "createdVariants": 25,
    "jobId": "job_cm8a91xkz..."
  },
  "createdProducts": 10,
  "createdVariants": 25,
  "jobId": "job_cm8a91xkz...",
  "message": "Successfully imported 10 product(s) with 25 variant(s)."
}

Validation Error Response (400 Bad Request):
If any rows fail validation, the entire file is rejected in an atomic transaction
so the database remains clean. Clear, actionable row-specific errors are returned:
{
  "success": false,
  "error": "Import validation failed",
  "errors": [
    "Row 3: price must be a valid number greater than 0",
    "Row 5: weight is mandatory for category Electronics",
    "Row 8: variant_details must be a valid JSON object string (e.g. {\"Color\":\"Red\"})",
    "Product 'Summer T-Shirt' (rows 12, 13): conflicting product_name for the same product group"
  ]
}

Plan Limit Exceeded Response (403 Forbidden):
{
  "success": false,
  "error": "This import would create 15 products but your plan allows 50 total (40 in use). Upgrade to add more."
}

KEY NOTES ON SPREADSHEET RULES:
- Simplified Variant Details: Instead of typing JSON with braces and quotes, sellers can simply enter natural key-value pairs like:
  `color: Black, size: Regular` or `color: Gold | size: Premium` (comma, semicolon, or pipe separated). Standard JSON like `{"color":"Black","size":"Regular"}` is also fully supported.
- Required Variant Fields: Every row MUST have `variant_name`, `price`, and `stock`.
- Images Separator: When providing multiple images in `product_variant_images`, separate them with `|` (e.g. `https://s3.../img1.jpg | https://s3.../img2.jpg`).
- Master Image: The master image of the product is automatically taken from the first image of the first variant.
- Category Weight Requirement: If an admin configured a category with `weightMandatory = true`, the `weight` column must be greater than 0, otherwise import will fail with a friendly prompt.

7. MULTI-VARIANT GROUPING & AUTO-CATEGORY LOGIC
================================================================================

1. Multi-Variant Grouping:
   - Rows in the spreadsheet that have the exact same `product_name` (case-insensitive)
     are automatically merged into a single parent `Product` record with multiple
     `ProductVariant` records.
   - Example:
     Row 2: product_name = "Nike Air Max", variant_name = "Size 9 / Blue"
     Row 3: product_name = "Nike Air Max", variant_name = "Size 10 / Red"
     -> Result: 1 Product ("Nike Air Max") with 2 child Variants.
   - All rows belonging to the same `product_name` must share the same `category`.

2. Intelligent Category Matching & Auto-Creation:
   - When processing the `category` column:
     Step A: Looks for an exact or fuzzy match among the seller's selected categories.
     Step B: If not selected by the seller, looks across all active marketplace categories.
             If found, it automatically connects that category to the seller's account.
     Step C: If no existing marketplace category matches, the system automatically
             creates a brand new active Category, links it to the seller, and sets
             the category icon/banner from the first variant image uploaded in the file!

================================================================================
8. SUBSCRIPTION LIMITS & ERROR HANDLING
================================================================================

1. Product Limit Enforcement:
   Before any records are inserted, the system queries the seller's active plan:
   `checkProductLimit(seller.id)`
   - If the seller's plan limit is reached (e.g. Free plan allows 50 products and
     seller already has 50), the upload is rejected with HTTP 403.
   - If the new import would cause the total to exceed the limit (e.g. 45 current +
     10 in file > 50 limit), the upload is rejected with HTTP 403 explaining the
     exact count.

2. Error Code Matrix:
| Status Code | Meaning            | Common Cause                                              |
| :---------- | :----------------- | :-------------------------------------------------------- |
| 200 OK      | Import Success     | Products and variants created, AI job triggered.          |
| 400 Bad Req | Validation Error   | Invalid spreadsheet syntax, missing required fields.      |
| 401 Unauth  | Unauthorized       | Missing or expired Bearer token.                          |
| 403 Forbid  | Forbidden          | Seller pending approval, suspended, or plan limit reached.|
| 404 Not Fnd | Not Found          | Seller profile does not exist.                            |
| 500 Server  | Internal Error     | File parsing error or database connectivity issue.        |

9.1 FLUTTER (DART) INTEGRATION
--------------------------------------------------------------------------------

```dart
import 'dart:io';
import 'package:dio/dio.dart';

class BulkProductService {
  final Dio dio = Dio(BaseOptions(
    baseUrl: 'https://your-domain.com',
    headers: {'Accept': 'application/json'},
  ));

  // 1. Bulk Upload Images
  Future<List<String>> uploadBulkImages({
    required List<File> imageFiles,
    required String token,
  }) async {
    final formData = FormData();
    for (var file in imageFiles) {
      formData.files.add(MapEntry(
        'files',
        await MultipartFile.fromFile(file.path, filename: file.path.split('/').last),
      ));
    }

    final response = await dio.post(
      '/mobileapi/product-seller/upload/bulk-images',
      data: formData,
      options: Options(headers: {'Authorization': 'Bearer $token'}),
    );

    if (response.statusCode == 200 && response.data['success'] == true) {
      final images = response.data['data']['images'] as List;
      return images.map((img) => img['url'] as String).toList();
    }
    throw Exception(response.data['error'] ?? 'Image upload failed');
  }

  // 2. Download Template
  Future<void> downloadTemplate({
    required String savePath,
    required String token,
    String format = 'xlsx',
  }) async {
    await dio.download(
      '/mobileapi/product-seller/product/bulk-template?format=$format&dummy=true',
      savePath,
      options: Options(headers: {'Authorization': 'Bearer $token'}),
    );
  }

  // 3. Bulk Import Spreadsheet
  Future<Map<String, dynamic>> importProducts({
    required File spreadsheetFile,
    required String token,
  }) async {
    final formData = FormData.fromMap({
      'file': await MultipartFile.fromFile(
        spreadsheetFile.path,
        filename: spreadsheetFile.path.split('/').last,
      ),
    });

    final response = await dio.post(
      '/mobileapi/product-seller/product/bulk-import',
      data: formData,
      options: Options(headers: {'Authorization': 'Bearer $token'}),
    );

    if (response.statusCode == 200 && response.data['success'] == true) {
      return response.data['data']; // contains createdProducts, createdVariants, jobId
    } else {
      final errors = response.data['errors'];
      if (errors != null && errors is List) {
        throw Exception(errors.join('\n'));
      }
      throw Exception(response.data['error'] ?? 'Import failed');
    }
  }
}
```

9.2 REACT NATIVE (AXIOS / FETCH) INTEGRATION

```typescript
import axios from 'axios';

const API_BASE = 'https://your-domain.com';

// 1. Bulk Upload Images
export async function uploadBulkImages(images: Array<{ uri: string; name: string; type: string }>, token: string) {
  const formData = new FormData();
  images.forEach((img) => {
    formData.append('files', {
      uri: img.uri,
      name: img.name,
      type: img.type,
    } as any);
  });

  const res = await axios.post(`${API_BASE}/mobileapi/product-seller/upload/bulk-images`, formData, {
    headers: {
      Authorization: `Bearer ${token}`,
      'Content-Type': 'multipart/form-data',
    },
  });
  return res.data.data.images; // Array of { id, url, filename, size, ... }
}

// 2. Import Products Spreadsheet
export async function importProducts(file: { uri: string; name: string; type: string }, token: string) {
  const formData = new FormData();
  formData.append('file', {
    uri: file.uri,
    name: file.name,
    type: file.type,
  } as any);

  try {
    const res = await axios.post(`${API_BASE}/mobileapi/product-seller/product/bulk-import`, formData, {
      headers: {
        Authorization: `Bearer ${token}`,
        'Content-Type': 'multipart/form-data',
      },
    });
    return res.data.data; // { createdProducts, createdVariants, jobId }
  } catch (err: any) {
    if (err.response?.data?.errors) {
      throw new Error(err.response.data.errors.join('\n'));
    }
    throw new Error(err.response?.data?.error || 'Import failed');
  }
}
```
