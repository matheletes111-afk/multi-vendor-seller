1. ARCHITECTURAL OVERVIEW
================================================================================
The MEEEM Product Seller mobile app provides merchants with complete, real-time
visibility over their package deliveries.

When an order is assigned to a delivery rider (via automated proximity cascade
or merchant manual assignment), the seller can:
1. View the assigned rider's name, phone, photo, vehicle number, and plate.
2. Track the live moving rider icon on Google Maps in real-time (<50ms latency).
3. Monitor current telemetry: Speed (km/h), Bearing Heading (0-360°), and straight-line
   distance (km) from store to drop-off.
4. Directly call or message the rider.
5. Reassign or trigger auto-dispatch if a rider becomes unresponsive.

3. REAL-TIME RIDER GPS TELEMETRY INTEGRATION
================================================================================

--------------------------------------------------------------------------------
3.1 Primary Streaming Channel: Socket.IO WebSocket
--------------------------------------------------------------------------------
The backend broadcasts rider position updates over WebSockets directly to the
room subscribed for this order.

- WebSocket Server URL: `https://<domain>:3001` (or `https://<domain>` with Socket.IO path)
- Protocol: Socket.IO v4+
- Event Format: JSON
- Health Check: `GET https://<domain>:3001/health`
  Returns: `{"status": "ok", "service": "meeem-socket-server"}`
  (Useful for DevOps, Docker, PM2, and load balancer uptime health monitoring)
- Internal Location Relay: `POST https://<domain>:3001/internal/location`
  Body: `{"riderId": "...", "orderId": "...", "latitude": 12.34, "longitude": 56.78, "heading": 90, "speed": 25}`
  (Relays REST location updates into `order:<orderId>` and `admin:fleet` socket rooms)

--------------------------------------------------------------------------------
3.2 Socket Connection & Room Subscription
--------------------------------------------------------------------------------
When the seller opens the Order Details page on mobile:

1. Establish Socket.IO connection:
   ```dart
   final socket = IO.io('https://<domain>:3001', <String, dynamic>{
     'transports': ['websocket'],
     'autoConnect': false,
     'auth': { 'token': 'Bearer <sellerAccessToken>' }
   });
   socket.connect();
   ```

2. Join Order Room upon connection:
   ```dart
   socket.onConnect((_) {
     socket.emit('join_order', { 'orderId': orderId });
     print('Subscribed to live tracking room for order: $orderId');
   });
   ```

--------------------------------------------------------------------------------
3.3 Live Position Broadcast Event (`order:rider_moved`)
--------------------------------------------------------------------------------
Listen for live coordinate updates from the server:

```dart
socket.on('order:rider_moved', (data) {
  // Guard for multi-vendor orders: ensure event belongs to currently tracked rider
  final String? activeRiderId = activeDeliveryTracking?['rider']?['id'];
  if (activeRiderId != null && data['riderId'] != null && data['riderId'] != activeRiderId) {
    return; // Ignore updates from other riders delivering separate packages for the same order
  }

  final double lat = data['latitude'];
  final double lng = data['longitude'];
  final double heading = (data['heading'] ?? 0).toDouble();
  final double speed = (data['speed'] ?? 0).toDouble();
  final int timestamp = data['timestamp'] ?? DateTime.now().millisecondsSinceEpoch;

  // Update Rider Marker position & rotate bearing on Google Maps
  updateRiderMarker(LatLng(lat, lng), heading, speed);
});
```

BROADCAST EVENT PAYLOAD SCHEMA:
{
  "orderId": "cuid_order_123",
  "riderId": "cuid_rider_888",
  "latitude": 8.484245,
  "longitude": -13.234125,
  "heading": 145.0,
  "speed": 28.5,
  "timestamp": 1724838930000
}

--------------------------------------------------------------------------------
3.4 Fallback Polling Strategy (REST API)
--------------------------------------------------------------------------------
If the mobile device switches between WiFi and 4G/5G causing a temporary socket
disconnect:
- Poll `GET /mobileapi/product-seller/orders/:id` every 10 to 15 seconds.
- Extract `activeDeliveryTracking.currentLocation` and update the map marker.

4. MOBILE MAP UI IMPLEMENTATION GUIDELINES
================================================================================

--------------------------------------------------------------------------------
4.1 Multi-Point Map Rendering
--------------------------------------------------------------------------------
Render 3 distinct anchors on the Google Maps view:
1. **Store Marker** (Blue Store Icon):
   `activeDeliveryTracking.pickupLocation.latitude / longitude`
2. **Rider Moving Marker** (Rotatable Bike / Scooter Icon):
   `activeDeliveryTracking.currentLocation.latitude / longitude`
3. **Destination Marker** (Red Destination Pin):
   Geocoded from `activeDeliveryTracking.destinationLocation`

--------------------------------------------------------------------------------
4.2 Custom Map Markers & Bearing Rotation
--------------------------------------------------------------------------------
* Smoothly interpolate marker positions between updates using `LatLngTween` or
  animation controllers (duration: 1000ms).
* Rotate the vehicle marker to match `heading` (0° = North, 90° = East, 180° = South, 270° = West).

--------------------------------------------------------------------------------
4.3 Dynamic Polyline Route Line
--------------------------------------------------------------------------------
Draw a vibrant blue polyline between the Rider position and the Destination:
- Color: `#2563EB` (Primary Blue)
- Width: 4dp
- Points: `[ RiderLatLng, DestinationLatLng ]`

6. SAMPLE FLUTTER CODE IMPLEMENTATION
================================================================================

```dart
import 'package:flutter/material.dart';
import 'package:google_maps_flutter/google_maps_flutter.dart';
import 'package:socket_io_client/socket_io_client.dart' as IO;

class SellerOrderTrackingMap extends StatefulWidget {
  final String orderId;
  final LatLng initialRiderLocation;
  final LatLng storeLocation;
  final LatLng customerLocation;

  const SellerOrderTrackingMap({
    Key? key,
    required this.orderId,
    required this.initialRiderLocation,
    required this.storeLocation,
    required this.customerLocation,
  }) : super(key: key);

  @override
  _SellerOrderTrackingMapState createState() => _SellerOrderTrackingMapState();
}

class _SellerOrderTrackingMapState extends State<SellerOrderTrackingMap> {
  late GoogleMapController _mapController;
  late IO.Socket _socket;
  LatLng? _riderPos;
  double _heading = 0.0;
  double _speed = 0.0;

  @override
  void initState() {
    super.initState();
    _riderPos = widget.initialRiderLocation;
    _initSocket();
  }

  void _initSocket() {
    _socket = IO.io('https://<domain>:3001', <String, dynamic>{
      'transports': ['websocket'],
      'autoConnect': true,
    });

    _socket.onConnect((_) {
      _socket.emit('join_order', {'orderId': widget.orderId});
    });

    _socket.on('order:rider_moved', (data) {
      // Filter out telemetry from other riders if multi-vendor order has multiple packages
      if (mounted && data['latitude'] != null && data['longitude'] != null) {
        setState(() {
          _riderPos = LatLng(data['latitude'], data['longitude']);
          _heading = (data['heading'] ?? 0).toDouble();
          _speed = (data['speed'] ?? 0).toDouble();
        });
      }
    });
  }

  @override
  void dispose() {
    _socket.disconnect();
    _socket.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final markers = <Marker>{
      Marker(
        markerId: const MarkerId('store'),
        position: widget.storeLocation,
        icon: BitmapDescriptor.defaultMarkerWithHue(BitmapDescriptor.hueAzure),
        infoWindow: const InfoWindow(title: 'Your Store (Pickup)'),
      ),
      Marker(
        markerId: const MarkerId('customer'),
        position: widget.customerLocation,
        icon: BitmapDescriptor.defaultMarkerWithHue(BitmapDescriptor.hueRed),
        infoWindow: const InfoWindow(title: 'Customer Destination'),
      ),
      if (_riderPos != null)
        Marker(
          markerId: const MarkerId('rider'),
          position: _riderPos!,
          rotation: _heading,
          icon: BitmapDescriptor.defaultMarkerWithHue(BitmapDescriptor.hueBlue),
          infoWindow: InfoWindow(title: 'Rider (${_speed.toStringAsFixed(1)} km/h)'),
        ),
    };

    return GoogleMap(
      initialCameraPosition: CameraPosition(target: widget.storeLocation, zoom: 14),
      markers: markers,
      onMapCreated: (controller) => _mapController = controller,
    );
  }
}
```
