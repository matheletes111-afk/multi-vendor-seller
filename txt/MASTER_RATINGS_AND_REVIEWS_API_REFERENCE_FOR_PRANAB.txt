1. STANDARD CONVENTIONS & DATA FORMATS
================================================================================

Standard Field Formats:
• Rating Score (averageRating / rating): Double / Float (e.g. 4.8, range 0.0 to 5.0, rounded to 1 decimal place).
• Total Reviews Count (reviewsCount / reviewCount / totalReviews): Integer (e.g. 38, count of all reviews).
• Hotel Star Classification (starRating / star_rating): Integer (1 to 5).
• Timestamps (createdAt / updatedAt): ISO 8601 String (e.g. "2026-08-18T10:15:30.000Z").
• Media Lists (images / reviewGallery): Array of HTTPS CDN URL strings.
• Review Star Breakdown: Key-value map of star ratings "1" through "5" mapping to review counts.

Standard Breakdown Format:
{
  "5": 28,
  "4": 7,
  "3": 2,
  "2": 1,
  "1": 0
}

--------------------------------------------------------------------------------
2.1 Product Listing & Search Results
--------------------------------------------------------------------------------
Endpoints:
  • GET  /mobileapi/category/:id
  • GET  /mobileapi/subcategory/:id
  • POST /mobileapi/browse
  • GET  /mobileapi/search

Authentication: None (Public / Guest)

Query Parameters (for GET /mobileapi/search):
  • q: Search keyword string
  • page: Page number (default: 1)
  • limit: Items per page (default: 20, max: 100)
  • categoryId: (Optional) Filter by category UUID
  • subcategoryId: (Optional) Filter by subcategory UUID

6. CUSTOMER REVIEW SUBMISSION APIS
================================================================================

--------------------------------------------------------------------------------
6.1 Products & Services Review Submission (Delivered Order Item)
--------------------------------------------------------------------------------
Endpoint: POST /mobileapi/customer/reviewrating
Authentication: Bearer <Customer Access Token> (Required)
Content-Type: multipart/form-data

Form-Data Parameters:
  • orderItemId (string, required): Order Item UUID
  • rating (integer, required): 1 to 5
  • comment (string, optional): Review text (max 1000 chars)
  • images (file[], optional): Up to 5 image files (jpeg/png/webp)

Success Response (HTTP 201):
{
  "success": true,
  "message": "Review submitted successfully",
  "data": {
    "id": "rev_001",
    "rating": 5,
    "comment": "Exceptional sound clarity and battery life!",
    "images": ["https://cdn.meeem.com/reviews/headphones_1.jpg"],
    "createdAt": "2026-08-18T10:15:30.000Z"
  }
}

7. ERROR HANDLING & HTTP STATUS CODES
================================================================================

Standard Error Response Schema:
{
  "success": false,
  "error": "Descriptive error message"
}

HTTP Status Codes:
• 200 OK: Request succeeded and data returned.
• 201 Created: Review created successfully.
• 400 Bad Request: Missing or invalid parameters (e.g. rating not between 1 and 5).
• 401 Unauthorized: Bearer token missing, expired, or invalid.
• 403 Forbidden: Customer does not have permission (e.g. order not delivered or booking not confirmed).
• 404 Not Found: Entity (Product, Service, Hotel, Food Item, or Review) does not exist.
• 409 Conflict: Review already submitted by user (use PUT to edit).
• 500 Internal Server Error: Unexpected server failure.
