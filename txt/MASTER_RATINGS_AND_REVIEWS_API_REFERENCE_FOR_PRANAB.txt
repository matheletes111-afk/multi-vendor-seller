1. STANDARD CONVENTIONS & DATA FORMATS
================================================================================

1.1 Live Rating Computation Standard
--------------------------------------
All listing and feed endpoints compute ratings dynamically from the database:

  averageRating = SUM(reviews[].rating) / COUNT(reviews)
  
  - Result is rounded to 1 decimal place (e.g. 4.3, not 4.27)
  - If an entity has 0 reviews: averageRating = 0.0, reviewCount = 0
  - Values are NEVER hardcoded, cached, or assumed

Standard Field Formats:
  - Rating Score (rating / averageRating): Float, range 0.0–5.0, 1 decimal place
  - Review Count (review_count / reviewCount / totalReviews / reviewsCount): Integer
  - Hotel Star Classification (starRating / star_rating): Integer (1–5)
    NOTE: starRating (property classification) is SEPARATE from averageRating (review score)
  - Timestamps (createdAt / updatedAt): ISO 8601 String
  - Media Lists (images / reviewGallery): Array of HTTPS CDN URL strings
  - Review Star Breakdown: Key-value map, keys "1" through "5"

1.2 Dual-Compatibility Field Standard
---------------------------------------
Every listing item includes rating fields under MULTIPLE key names so that
both snake_case and camelCase consumers receive the exact same live value:

{
  "rating": 4.3,
  "averageRating": 4.3,
  "review_count": 12,
  "reviewCount": 12,
  "totalReviews": 12,
  "reviewsCount": 12
}

When 0 reviews exist:
{
  "rating": 0.0,
  "averageRating": 0.0,
  "review_count": 0,
  "reviewCount": 0,
  "totalReviews": 0,
  "reviewsCount": 0
}

Standard Breakdown Format (detail pages only):
{
  "5": 28,
  "4": 7,
  "3": 2,
  "2": 1,
  "1": 0
}

7. ERROR HANDLING & HTTP STATUS CODES
================================================================================

Standard Error Response Schema:
{
  "success": false,
  "error": "Descriptive error message"
}

HTTP Status Codes:
• 200 OK: Request succeeded and data returned.
• 201 Created: Review created successfully.
• 400 Bad Request: Missing or invalid parameters (e.g. rating not between 1 and 5).
• 401 Unauthorized: Bearer token missing, expired, or invalid.
• 403 Forbidden: Customer does not have permission (e.g. order not delivered or booking not confirmed).
• 404 Not Found: Entity (Product, Service, Hotel, Food Item, or Review) does not exist.
• 409 Conflict: Review already submitted by user (use PUT to edit).
• 500 Internal Server Error: Unexpected server failure.
