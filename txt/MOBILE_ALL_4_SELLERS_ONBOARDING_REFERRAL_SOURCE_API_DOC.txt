================================================================================
MOBILE API DOCUMENTATION: "WHERE DID YOU HEAR ABOUT US" (ALL 4 PANELS)
================================================================================

This document details the Mobile API updates across all 4 Seller Panels:
1. Product Seller
2. Service Seller
3. Restaurant Seller
4. Hotel Seller

A new static dropdown field ("hearAboutUs") has been added to the final Onboarding Agreement Step, alongside the 4 Legal Agreement Checkboxes. The list of available referral options ("hearAboutUsOptions") is exposed in all onboarding GET endpoints.

Summary of Final Agreement Step UI (All 4 Sellers):
1. Referral Dropdown ("Where did you hear about our platform?") -> hearAboutUs
2. Checkbox 1: General Seller / Vendor Terms & Conditions -> agreedToTerms
3. Checkbox 2: Privacy Policy & Data Compliance -> agreedToPrivacy
4. Checkbox 3: Vendor Agreement / Return & Cancellation Policy -> agreedToReturnPolicy
5. Checkbox 4: Payment Settling & Commission Terms -> agreedToCommission

(Note: All 4 checkboxes can be sent in the POST payload for any seller type; the backend automatically accepts and maps them safely).

B. POST Final Step (Mobile Step 5: Agreement & Completion)
---------------------------------------------------------
- Method: POST
- URL: /mobileapi/product-seller/onboarding
- Headers:
  Authorization: Bearer <TOKEN>
  Content-Type: application/json (or multipart/form-data)

- Request Payload (JSON):
{
  "step": 5,
  "data": {
    "agreedToTerms": true,
    "agreedToCommission": true,
    "agreedToReturnPolicy": true,
    "agreedToPrivacy": true,
    "hearAboutUs": "Google / Search Engine"
  }
}

- Request Payload (Multipart / Form-Data Alternative):
  - mobileStep: 5
  - agreedToTerms: "true"
  - agreedToCommission: "true"
  - agreedToReturnPolicy: "true"
  - agreedToPrivacy: "true"
  - hearAboutUs: "Google / Search Engine"

- Response (200 OK):
{
  "success": true,
  "message": "Step 5 saved successfully",
  "data": {
    "nextStep": null,
    "onboardingCompleted": true
  }
}
