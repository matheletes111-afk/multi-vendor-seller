================================================================================
1. OVERVIEW & CAPABILITIES
================================================================================
This document provides complete implementation specifications for the Restaurant
Seller Mobile API:

1. Bulk Food Upload:
   Sellers can upload hundreds of dishes at once using Microsoft Excel (.xlsx)
   or CSV (.csv) spreadsheets, complete with validation, error reports, and
   synchronous transaction creation.

2. Bulk Media Image Gallery:
   Sellers can upload multiple food dish pictures at once, view them in a gallery,
   filter by used/unused status, and copy single or multiple image URLs
   (separated with '|') to paste directly into their bulk spreadsheets or attach
   to single dishes.

3. Selling Price & Food Discount System:
   Both single food creation/editing and bulk spreadsheet imports accept:
   - "price" (Actual listed MRP / Menu Price)
   - "sellingPrice" (The final discounted price that customers pay)
   The backend automatically calculates:
     discount = price - sellingPrice (if sellingPrice < price, else 0)
   Customers and checkout will always be charged the sellingPrice.

================================================================================
2. PRICING & DISCOUNT ARCHITECTURE (MRP vs SELLING PRICE)
================================================================================
Field Definitions in Database & API:
- "price" (Float, required, > 0):
  The regular listed MRP (Maximum Retail Price) / Menu price of the food item.
- "sellingPrice" (Float, optional, > 0 and <= price):
  The discounted selling price that the restaurant wants to sell the dish for.
  If omitted or equal to "price", no discount is applied.
- "discount" (Float, auto-computed and stored in DB):
  Computed as: Math.max(0, price - sellingPrice).
  If sellingPrice is not provided, discount defaults to 0.

Effective Customer Price Formula:
  effectivePrice = Math.max(0, price - discount)

Mobile App Seller Form Validation:
- Rule 1: price > 0 (required)
- Rule 2: sellingPrice > 0 (if entered)
- Rule 3: sellingPrice <= price (selling price cannot be higher than MRP)
- Rule 4: If seller clears sellingPrice, sending "" on PUT sets discount to 0.
- Rule 5: If the seller lowers price below existing discount, the discount resets to 0.

Live UI Preview Calculation for Seller:
  discountAmount = price - sellingPrice
  discountPercentage = Math.round((discountAmount / price) * 100)

5.2 UPLOAD & IMPORT SPREADSHEET
--------------------------------------------------------------------------------
Endpoint: POST /mobileapi/restaurant-seller/foods/bulk-import
Headers:
  Authorization: Bearer <MOBILE_ACCESS_TOKEN>
  Content-Type: multipart/form-data

Form Data:
  - file: File (.xlsx or .csv, max 8MB, max 500 rows)

Execution Model:
- The import is SYNCHRONOUS and ALL-OR-NOTHING.
- If any row fails validation, the entire batch is rejected, and an array of descriptive
  row-by-row error strings is returned.
- If all rows are valid, dishes are created in a database transaction, and any
  referenced media gallery images are automatically marked with isUsed: true.

Success Response (200 OK):
{
  "success": true,
  "count": 15,
  "message": "Successfully imported 15 food items."
}

Validation Failure Response (400 Bad Request):
{
  "success": false,
  "error": "Import validation failed",
  "errors": [
    "Row 3: selling price (120) cannot exceed regular price (100) for \"Butter Chicken\"",
    "Row 7: food_name is required",
    "Row 9: valid price greater than 0 is required for \"Mango Lassi\""
  ]
}

6. SPREADSHEET COLUMN SPECIFICATION & RULES (8 COLUMNS)
================================================================================
The Excel or CSV spreadsheet contains exactly 8 columns in order:

┌────┬──────────────────────┬──────────┬──────────┬────────────────────────────────────────────────────────┐
│ #  │ Column Header Name   │ Type     │ Required │ Description & Rules                                    │
├────┼──────────────────────┼──────────┼──────────┼────────────────────────────────────────────────────────┤
│ 1  │ category             │ String   │ YES      │ Category (e.g. "Pizza", "Biryani", "Drinks", "Dessert")│
│ 2  │ food_name            │ String   │ YES      │ Name of dish (e.g. "Chicken Shawarma Plate")          │
│ 3  │ price                │ Number   │ YES      │ Regular Listed MRP price (> 0) (e.g. 150.00)           │
│ 4  │ selling_price        │ Number   │ NO       │ Final price customer pays (e.g. 125.00). Must be <= MRP│
│    │                      │          │          │ Leave blank for no discount.                           │
│ 5  │ is_veg               │ String   │ YES      │ "YES" / "TRUE" / "1" for veg; "NO" / "0" for non-veg   │
│ 6  │ description          │ String   │ NO       │ Dish description, ingredients, notes                   │
│ 7  │ food_images          │ String   │ NO       │ URLs separated by pipe '|' (e.g. url1|url2|url3)       │
│ 8  │ is_active            │ String   │ NO       │ "YES" / "TRUE" / "1" (default: true)                   │
└────┴──────────────────────┴──────────┴──────────┴────────────────────────────────────────────────────────┘

Spreadsheet Aliases Supported:
- food_name: "name", "dish_name", "item_name", "title"
- selling_price: "sellingPrice", "discount", "offer_price", "discounted_price"
- food_images: "images", "image_urls", "photos"

Sample Spreadsheet Row:
category: Biryani
food_name: Chicken Dum Biryani
price: 160
selling_price: 130
is_veg: NO
description: Long grain basmati rice with chicken and aromatic spices.
food_images: https://res.cloudinary.com/demo/image/upload/v1/b1.webp|https://res.cloudinary.com/demo/image/upload/v1/b2.webp

Database Result:
- price: 160.00
- discount: 30.00 (160 - 130)
- sellingPrice: 130.00

8. COMPLETE PAYLOAD & RESPONSE REFERENCE FOR MOBILE DEVS
================================================================================
HTTP Status Codes:
- 200 OK: Request succeeded.
- 201 Created: New resource created.
- 400 Bad Request: Missing required fields, sellingPrice > price, or invalid spreadsheet.
- 401 Unauthorized: Invalid or missing bearer token.
- 403 Forbidden: User role is not SELLER_RESTAURANT.
- 404 Not Found: Food item or seller account not found.
- 500 Internal Server Error: Server error.

--- 9.1 Flutter / Dart Food Upload Function ---
```dart
import 'dart:io';
import 'package:http/http.dart' as http;

Future<bool> createFoodItem({
  required String token,
  required String name,
  required String category,
  required double price,
  double? sellingPrice,
  required bool isVeg,
  String? description,
  List<File>? newImages,
  String? galleryImageUrls,
}) async {
  final uri = Uri.parse('https://your-domain/mobileapi/restaurant-seller/foods');
  final request = http.MultipartRequest('POST', uri);
  request.headers['Authorization'] = 'Bearer $token';

  request.fields['name'] = name;
  request.fields['category'] = category;
  request.fields['price'] = price.toString();
  if (sellingPrice != null && sellingPrice > 0) {
    request.fields['sellingPrice'] = sellingPrice.toString();
  }
  request.fields['isVeg'] = isVeg ? 'true' : 'false';
  if (description != null) request.fields['description'] = description;
  if (galleryImageUrls != null) request.fields['imageUrls'] = galleryImageUrls;

  if (newImages != null) {
    for (final img in newImages) {
      request.files.add(await http.MultipartFile.fromPath('images', img.path));
    }
  }

  final response = await request.send();
  return response.statusCode == 201 || response.statusCode == 200;
}
```

--- 9.2 React Native / TypeScript Food Upload Function ---
```tsx
export async function createFoodItem(token: string, data: {
  name: string;
  category: string;
  price: number;
  sellingPrice?: number;
  isVeg: boolean;
  description?: string;
  newImages?: Array<{ uri: string; name: string; type: string }>;
  galleryImageUrls?: string;
}) {
  const formData = new FormData();
  formData.append('name', data.name);
  formData.append('category', data.category);
  formData.append('price', String(data.price));
  if (data.sellingPrice && data.sellingPrice > 0) {
    formData.append('sellingPrice', String(data.sellingPrice));
  }
  formData.append('isVeg', data.isVeg ? 'true' : 'false');
  if (data.description) formData.append('description', data.description);
  if (data.galleryImageUrls) formData.append('imageUrls', data.galleryImageUrls);

  if (data.newImages) {
    data.newImages.forEach((img) => {
      formData.append('images', {
        uri: img.uri,
        name: img.name,
        type: img.type,
      } as any);
    });
  }

  const res = await fetch('https://your-domain/mobileapi/restaurant-seller/foods', {
    method: 'POST',
    headers: {
      Authorization: `Bearer ${token}`,
      // Note: Do not set Content-Type manually when using FormData in React Native
    },
    body: formData,
  });

  return await res.json();
}
```
