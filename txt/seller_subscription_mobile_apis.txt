# Seller Subscription Mobile APIs

These APIs allow product and service sellers to manage their subscription plans via the mobile app.

## 1. Get Subscription and Plans
Retrieves the current active subscription and all available plans for the authenticated seller.

### Product Seller
- **Endpoint**: `GET /mobileapi/product-seller/subscription`
- **Authentication**: Required (Bearer Token - Product Seller)

### Service Seller
- **Endpoint**: `GET /mobileapi/service-seller/subscription`
- **Authentication**: Required (Bearer Token - Service Seller)

## 2. Update Subscription Plan
Updates or switches the seller's current subscription plan. 

### Product Seller
- **Endpoint**: `POST /mobileapi/product-seller/subscription`
- **Authentication**: Required (Bearer Token - Product Seller)

### Service Seller
- **Endpoint**: `POST /mobileapi/service-seller/subscription`
- **Authentication**: Required (Bearer Token - Service Seller)

### Request Body:
```json
{
  "planId": "plan_id_2",
  "planName": "PREMIUM",
  "couponCode": "SAVE20"
}
```
> **Important Rule:** Only **Paid Plans** (`price > 0`, `isPurchasable: true`) can be activated, extended, or queued. Passing `FREE` (`price <= 0`) returns `400 Bad Request` (`"Free introductory plan is granted once upon admin approval and cannot be extended or repurchased."`). Mobile apps must hide the Extend/Queue/Purchase button whenever `plan.isPurchasable === false` or `plan.canExtend === false`.

### Response Structure:
```json
{
  "success": true,
  "message": "Subscription updated successfully",
  "status": "ACTIVE",
  "subscription": {
    "id": "...",
    "planId": "...",
    "status": "ACTIVE",
    "periodStart": "2026-05-06T11:51:40.000Z",
    "periodEnd": "2026-06-05T11:51:40.000Z",
    "couponCode": "SAVE20",
    "discountAmount": 100,
    "paidPrice": 899,
    "plan": {
      "name": "PREMIUM",
      "displayName": "Premium Plan",
      ...
    }
  },
  "url": null
}
```

## 3. Lifecycle, Carry-Forward & Queueing Logic

### Free Plan (Strictly 1-Time on Admin Approval)
- **Assigned Once on Approval**: A 90-day (3-month) **FREE** introductory trial is automatically assigned **only once** when an Admin approves the seller account (`isApproved = true`).
- **Cannot Extend or Repurchase**: Sellers cannot extend, queue, or switch back to the Free plan. Mobile UI must check `isPurchasable` / `canExtend` (`false` for Free plan) and hide any Extend/Queue action button on the Free card.
- **Carry-Forward on Early Upgrade**: If a seller upgrades to a Paid plan before their 90-day Free trial ends, all remaining Free days are automatically added onto their new Paid pack!

### Paid Plans (Prepaid Packs & Queueing)
- **Active Paid Pack Queueing**: Recharging while a Paid pack is already `ACTIVE` schedules the new purchase with `status: "QUEUED"` (returned in `queuedPacks`), starting automatically when the current pack expires.
- **Expiration**: When a pack reaches `currentPeriodEnd` with no `QUEUED` pack waiting, status transitions to `EXPIRED` and the seller must recharge a Paid pack.

### Important Fields for Frontend
- **`status`**: If this is `CANCELED`, the seller should be prompted to upgrade/subscribe.
- **`currentPeriodEnd`**: Use this date to show the seller when their next renewal happens.

## Headers (Global for Mobile APIs)
All requests must include the following header for authentication:
- `Authorization`: `Bearer <MOBILE_ACCESS_TOKEN>`
