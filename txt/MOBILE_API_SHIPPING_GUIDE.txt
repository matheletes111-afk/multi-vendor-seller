1. OVERVIEW & CALCULATION FORMULA
--------------------------------------------------------------------------------
The backend shipping engine calculates multi-vendor delivery charges dynamically based on 3 distinct components:

  1) Weight-based Shipping Fee (weightShippingFee)
  2) Dimension-based Shipping Fee (dimensionShippingFee)
  3) Region-based Shipping Surcharge (regionShippingFee)

ADDITIVE & PER-SELLER PACKAGING FORMULA:
- Items from DIFFERENT sellers are packaged and shipped independently.
- Cart items are grouped by `sellerId`.
- Each seller's total delivery charge is calculated as:
  
    Seller Delivery Fee = Weight Fee + Dimension Fee + Region Fee

- Total Order Shipping Fee = Sum of all Seller Delivery Fees:
  
    Total Order Shipping = Seller A Fee + Seller B Fee + ...

NULL & ZERO WEIGHT/DIMENSION/REGION RULE:
- Missing, null, or 0 weight/dimensions are treated as 0 kg / 0 cm³.
- They are NOT skipped and do NOT automatically default to 0/FREE.
- Instead, 0 kg / 0 cm³ is looked up in the Admin-configured tier table (e.g. 0-5 kg tier or base tier) to return the Admin's configured delivery fee.
- If address region is null/unspecified or unlisted, it maps to "Other" region and applies the Admin "Other" region delivery surcharge.


2. REGION & DELIVERY ZONE PRIORITY MATCHING
--------------------------------------------------------------------------------
The delivery engine follows a strict 4-tier hierarchy for matching customer addresses to delivery zones and surcharges:

  1) Priority 1: Specific Delivery Zones (ZONE 1 to ZONE 15)
     - Evaluates street, building, sublocality, and area against 200+ specific location areas (e.g. PZ, Lumley, Wallace Johnson Street, Aberdeen, Kissy Road).
  2) Priority 2: Gemini AI Spatial Matching
     - Uses Gemini AI with spatial reasoning that prioritizes specific delivery zones (ZONE 1 to 15).
  3) Priority 3: Administrative Provinces (Western Area, Eastern Province, Northern Province, etc.)
     - Used ONLY if the location does not match any specific delivery zone.
  4) Priority 4: "Other" (Fallback).

AI Region Matcher API:
  POST /api/customer/checkout/ai-match-region
  Request:  { "addressLine1": "...", "city": "...", "state": "..." }
  Response: { "matchedRegion": "PZ", "zone": "ZONE 5", "charge": 50, ... }

CLEAN DISPLAY LABEL RULE:
  - If zone starts with "ZONE" (e.g. ZONE 5): Display "📍 PZ (ZONE 5)" or "📍 Lumley (ZONE 2)"
  - If zone is "Administrative Provinces":    Display "📍 Western Area"
  - If "Other":                               Display "📍 Other"
