================================================================================
          MEEEM MULTI-VENDOR MOBILE API - SHIPPING & REGION GUIDE
================================================================================

1. OVERVIEW & ADMINISTRATIVE REGIONS
--------------------------------------------------------------------------------
The backend calculates delivery fees based on 3 distinct components:
  1) Weight-based Shipping Fee (weightShippingFee)
  2) Dimension-based Shipping Fee (dimensionShippingFee)
  3) Region-based Shipping Fee (regionShippingFee)

IMPORTANT ZERO-FALLBACK RULE:
- If weight, dimensions, address region, or setting ranges are null, empty,
  or unconfigured, the charge for that specific component defaults to 0.00.

ADDITIVE FORMULA & MULTI-VENDOR CALCULATION:
- Per Seller Physical Fee = weightShippingFee + dimensionShippingFee
- Total Order Delivery Fee = Weight Fee + Dimension Fee + Region Fee
* Note: Weight Fee and Dimension Fee are ADDITIVE (Weight + Dimension).
* Note: Region shipping fee is a flat PER-ORDER surcharge based on delivery region.
  It is applied ONCE per order, regardless of how many sellers are in the cart.


2. MOBILE ADDRESS FORM & MAP REGION RESOLUTION
--------------------------------------------------------------------------------
When adding or updating a delivery address (via POST/PATCH /mobileapi/customer/checkout/addresses),
the app MUST present a dropdown for the 'state' field containing Sierra Leone's
Administrative Regions + Fallback:

  - Eastern Province
  - Northern Province
  - North West Province
  - Southern Province
  - Western Area
  - Other                      <-- Fallback region for custom/other destinations

MAP & REVERSE GEOCODING REGION EXTRACTION:
- When a customer picks a location on the Map or uses GPS reverse-geocoding (lat/lng):
  1) Extract the administrative region or city from the geocoding response.
  2) Map major cities/areas to standard regions (e.g. Freetown -> Western Area, Kenema -> Eastern Province, Bo -> Southern Province, Makeni -> Northern Province).
  3) If the geocoded location or city does not match any of the 5 main provinces, pass `state: "Other"`.
- The backend shipping engine automatically resolves map location strings and applies the "Other" region surcharge.

Region Fallback Rule:
- If the delivery address state does not match any of the 5 specific provinces above,
  the shipping calculator automatically falls back to the "Other" region delivery surcharge
  configured in Admin Settings. If "Other" is unconfigured, it defaults to 0.00.

Example Address JSON Payload (POST /mobileapi/customer/checkout/addresses):
{
  "fullName": "John Doe",
  "phone": "076123456",
  "addressLine1": "15 Circular Road",
  "addressLine2": "Apartment 4B",
  "city": "Freetown",
  "state": "Western Area",       <-- Select from regions, map reverse-geocode, or "Other"
  "postalCode": "00232",
  "country": "Sierra Leone",
  "isDefault": true
}

4. SUMMARY OF DEFAULT FALLBACKS & MAP RESOLUTION
--------------------------------------------------------------------------------
- Missing Weight / Variant Weight = null       => weightShippingFee = 0.00
- Missing Height/Width/Depth = null            => dimensionShippingFee = 0.00
- Unrecognized Map/Address Location            => Automatic fallback to "Other" charge
- Unconfigured "Other" Region                  => regionShippingFee = 0.00
- Service-only Orders (No Physical Products)   => All shipping fees = 0.00
