6. CONCRETE PRACTICAL EXAMPLE: HOW TO RECOVER 2 ACCIDENTALLY DELETED SELLERS
--------------------------------------------------------------------------------
SCENARIO:
While deleting test data on Live Neon DB, you accidentally delete 2 real sellers
(or 2 real products, orders, users, etc.). Because your local database "meeem_local"
and the file "backups/neon_backup_initial.dump" hold the complete snapshot,
here is EXACTLY how you restore them back into Live Neon DB.

================================================================================
EXAMPLE APPROACH A: THE FASTEST & EASIEST VISUAL WAY (pgAdmin 4)
================================================================================
STEP 1: Find the 2 deleted sellers in your Local Database:
1. Open pgAdmin 4.
2. In left panel: Servers -> PostgreSQL 18 -> Databases -> "meeem_local".
3. Right-click "meeem_local" -> click "Query Tool".
4. Run this query to find your 2 missing sellers:
   SELECT * FROM sellers WHERE id IN ('seller_id_1', 'seller_id_2');
   (Or search by name/email: SELECT * FROM sellers WHERE "userId" IN (...);)

STEP 2: Copy as INSERT Statement:
1. In the bottom "Data Output" panel, highlight the rows.
2. Right-click on the selected row(s) -> Select "Copy" -> "Copy as INSERT".
   (pgAdmin will generate the exact valid SQL INSERT statements for you!)

STEP 3: Paste and Execute on Live Neon DB:
1. In left panel: Servers -> "Neon-Live" (or right-click Servers -> Register Neon).
2. Right-click "neondb" on Neon -> click "Query Tool".
3. Paste the copied INSERT query into the editor.
4. Press F5 (or the Play / Execute button).
   Result: The 2 sellers are INSTANTLY restored back into Live Neon DB!

* NOTE FOR CASCADE TABLES (e.g., Stores or Products):
If deleting the sellers also removed their stores or products (due to CASCADE):
Do the exact same 3 steps for the child tables from local to live:
   SELECT * FROM stores WHERE "sellerId" IN ('seller_id_1', 'seller_id_2');
   SELECT * FROM products WHERE "sellerId" IN ('seller_id_1', 'seller_id_2');
   -> Copy as INSERT -> Execute on Live Neon!

================================================================================
EXAMPLE APPROACH B: RECOVERING DIRECTLY FROM .dump FILE VIA CLI
================================================================================
If you want to restore the entire "sellers" table (or any table) data from
the backup file directly back into Live Neon:

Run this single command in PowerShell:
& "C:\Program Files\PostgreSQL\18\bin\pg_restore.exe" -d "postgresql://neondb_owner:npg_pSb2Dfn1Gzhm@ep-blue-water-ad4901cs.c-2.us-east-1.aws.neon.tech/neondb?sslmode=require" --data-only --table=sellers "backups/neon_backup_initial.dump"

What this does:
- Reads the "sellers" table data from "neon_backup_initial.dump"
- Injects missing rows directly into Live Neon DB without touching any other tables!

================================================================================
EXAMPLE APPROACH C: USING CSV EXPORT / IMPORT (Single Table or Specific Rows)
================================================================================
If you only want to copy specific IDs via terminal:

Step 1: Export the 2 sellers from local meeem_local to a temporary CSV:
$env:PGPASSWORD='11111111'; & "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -h localhost -p 5432 -d meeem_local -c "\copy (SELECT * FROM sellers WHERE id IN ('seller_id_1', 'seller_id_2')) TO 'recovered_sellers.csv' WITH CSV HEADER"

Step 2: Import that CSV directly into Live Neon DB:
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" "postgresql://neondb_owner:npg_pSb2Dfn1Gzhm@ep-blue-water-ad4901cs.c-2.us-east-1.aws.neon.tech/neondb?sslmode=require" -c "\copy sellers FROM 'recovered_sellers.csv' WITH CSV HEADER"

Step 3: Delete the temporary CSV file:
Remove-Item 'recovered_sellers.csv'
