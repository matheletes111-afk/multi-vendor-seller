1. ARCHITECTURE OVERVIEW & HOW IT WORKS
--------------------------------------------------------------------------------
In Sierra Leone, AfriMoney Push USSD allows sellers to pay for ad campaigns directly
using their mobile phones without entering credit card details or navigating to an
external browser portal:

  1. Seller views their Ad list or Ad details in the Mobile App.
  2. If `ad.paymentStatus !== "COMPLETED"`, app displays a "Pay Now" button.
  3. Seller taps "Pay Now", enters their Africell mobile number (e.g. 080612072 or 033600171).
  4. App calls POST /mobileapi/.../pay-afrimoney with the seller's phone number.
  5. Backend calls the AfriMoney Gateway Bridge with external reference ID: "AD_{adId}".
  6. The seller's phone immediately receives a real-time Push USSD pop-up on their screen:
     "AfriMoney: Enter PIN to pay SLE <amount> to MEEEM SL".
  7. Seller types their 4-digit PIN on the handset to approve.
  8. AfriMoney processes the payment and sends an asynchronous server webhook to:
     POST https://www.meeemsl.com/api/afrimoney/callback
     which validates the reference ("AD_{adId}") and automatically marks in DB:
     - paymentStatus = "COMPLETED"
     - paymentMethod = "AFRIMONEY"
     - paidAt = <current timestamp>
     - afriTxnId = "<AfriMoney Transaction ID>"
     - afriFtxnId = "AD_{adId}"
     - afriMsisdn = "<Payer Phone Number>"
     - status = "PENDING_APPROVAL" (or "ACTIVE" based on campaign settings)
  9. Meanwhile, the mobile app polls GET /mobileapi/.../pay-afrimoney every 3 seconds.
  10. As soon as the backend confirms paymentStatus === "COMPLETED", the mobile app
      stops polling and shows the "Payment Successful!" screen.

3. AVAILABLE API ENDPOINTS
--------------------------------------------------------------------------------
To make integration seamless, the backend exposes both a Universal endpoint and
category-specific endpoints. All endpoints share the exact same logic, security,
and response structure.

A) Universal / Canonical Endpoint (Recommended for all apps):
   - POST /mobileapi/seller/ads/:id/pay-afrimoney
   - GET  /mobileapi/seller/ads/:id/pay-afrimoney

B) Category-Specific Endpoints (For drop-in compatibility with dedicated seller apps):
   1. Product Seller App:
      - POST /mobileapi/product-seller/ads/:id/pay-afrimoney
      - GET  /mobileapi/product-seller/ads/:id/pay-afrimoney

   2. Service Seller App:
      - POST /mobileapi/service-seller/ads/:id/pay-afrimoney
      - GET  /mobileapi/service-seller/ads/:id/pay-afrimoney

   3. Hotel Seller App:
      - POST /mobileapi/hotel-seller/admanagement/:id/pay-afrimoney
      - GET  /mobileapi/hotel-seller/admanagement/:id/pay-afrimoney

   4. Restaurant Seller App:
      - POST /mobileapi/restaurant-seller/admanagement/:id/pay-afrimoney
      - GET  /mobileapi/restaurant-seller/admanagement/:id/pay-afrimoney

* Note: Replace `:id` with the actual SellerAd ID (e.g. cmvv40o5i0001nb5s3pabzk2o).

--------------------------------------------------------------------------------
4. AUTHENTICATION & SECURITY (ZERO IDOR)
--------------------------------------------------------------------------------
Every request MUST include the standard mobile bearer token in the HTTP header:

  Authorization: Bearer <mobile_access_token>
  Content-Type: application/json

Security Enforcement:
- The backend verifies token validity, expiration, and user account status.
- Strict Ownership Scoping (Zero IDOR): The backend verifies that the ad belongs
  to the authenticated user (Product/Service Seller, Hotel Seller, Restaurant Seller,
  or Customer). If a seller tries to pay or inspect an ad belonging to someone else,
  the backend immediately blocks the request with HTTP 403 Forbidden.
- System Admins are permitted to view and process payments on behalf of sellers.

- If `ad.paymentStatus !== "COMPLETED"`: Show the "Pay Now" button prominently. Clicking it opens the AfriMoney Payment Modal.

================================================================================
ENDPOINT 1: INITIATE AFRIMONEY PAYMENT (PUSH USSD)
================================================================================
Method: POST
URL: /mobileapi/seller/ads/:id/pay-afrimoney
(Or category-specific path)

Request Headers:
  Authorization: Bearer <access_token>
  Content-Type: application/json

Request Body:
{
  "phone": "080612072"
}
* Note: The field name can be either "phone" or "msisdn".

Phone Number Formatting Rules:
- Supports standard Sierra Leone local format: 9 digits starting with 0
  (e.g., "080612072", "088123456", "030123456", "033600171", "077928995").
- Also supports 8 digits ("80612072") or international format ("+23280612072", "23280612072").
- Whitespace and non-numeric characters are safely stripped automatically by the API.

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

Scenario A: Success - Push USSD Sent to Phone (HTTP 200 OK)

  "paid": false,
  "txnId": "MP261030.1511.90074",

was sent to their phone, and start polling GET status every 3 seconds.

OR
{
  "success": false,
  "error": "Invalid phone number format. Please provide a valid Africell number (e.g. 080612072 or 033600171)"
}

{
  "success": false,
  "error": "Unauthorized: Invalid or expired token"

Scenario F: Cross-Tenant Access / IDOR Attempt (HTTP 403 Forbidden)
{

}

Scenario G: Ad Not Found (HTTP 404 Not Found)
{
  "success": false,
  "error": "Ad not found"
}

Scenario H: AfriMoney Gateway Failure (HTTP 400 Bad Request)
{
  "success": false,
  "error": "Subscriber number is inactive or not registered for AfriMoney"
}

How to use these payment fields in the mobile UI:
1. `paymentStatus`:
   - If "COMPLETED": Display a green "PAID" badge and receipt details. Hide "Pay Now" button.
   - If "PENDING": Display an amber "UNPAID" badge and show the "Pay Now" button.
   - If "FAILED": Display a red "FAILED" badge and show the "Retry Payment" button.
2. `paymentMethod`:
   - Shows which payment gateway was used ("AFRIMONEY", "FLOAT", etc.).
3. `afriTxnId`:
   - Display as "Transaction ID / Receipt #" on the ad detail screen for customer support reconciliation.
4. `afriMsisdn`:
   - Display as "Paid via Africell: 080612072".
5. `paidAt`:
   - Formatted local date/time when transaction completed.

7. RECOMMENDED MOBILE UI / UX LIFECYCLE (STEP-BY-STEP)
--------------------------------------------------------------------------------
1. Modal / Screen Launch:
   - Present the ad title and total payable amount (formatted in SLE, e.g. "SLE 10.00").
   - Phone Input field pre-filled with user's profile phone if available, or empty with
     placeholder "e.g. 080612072 or 033600171".
   - Button: "Send USSD Payment Prompt".

2. Button Click Handler:
   - Disable the button and display loading spinner: "Sending Push USSD...".
   - Call POST /mobileapi/seller/ads/:id/pay-afrimoney with { phone }.
   - If response status is 400/500:
     - Show in-context error banner directly above the input.
     - Re-enable the button.
   - If response is 200 with paid: true (already paid / zero budget):
     - Show success dialog and refresh ad screen.
   - If response is 200 with paymentStatus: "PENDING":
     - Transition modal to "Waiting for Authorization" view:
       "USSD prompt sent to [phone]! Please check your mobile phone screen and enter your AfriMoney PIN."
     - Show active spinner and a "Check Status Now" manual refresh button.
     - Start auto-polling.

3. Auto-Polling Algorithm:
   - Polling Interval: 3000 ms (every 3 seconds).
   - Maximum Polling Duration: 90 seconds (30 poll cycles).
   - On each poll:
     - Call GET /mobileapi/seller/ads/:id/pay-afrimoney silently.
     - If response data has `paid === true` or `paymentStatus === "COMPLETED"`:
       - Clear interval immediately.
       - Clear timeout.
       - Play success haptic / sound.
       - Show green success badge: "Payment Completed!".
       - Provide "Done" button that reloads ad list.
     - If response data has `paymentStatus === "FAILED"`:
       - Clear interval.
       - Display: "Payment authorization failed. Tap below to retry."
   - If 90 seconds elapse without confirmation:
     - Stop interval.
     - Display: "Authorization is taking longer than expected. If you already entered your PIN on your phone, tap 'Check Status Now' to refresh."
     - Allow user to tap "Check Status Now" or "Try Different Phone Number".

4. App State / Foreground Handling (Crucial for Mobile):
   - When the USSD popup opens on Android or iOS, the mobile app often triggers an
     `AppState` transition to `background` or `inactive`.
   - When the user finishes entering their PIN, the app transitions back to `active`.
   - On `AppState` becoming `active`, immediately trigger an instant status poll check!
     This provides immediate gratification without waiting for the next 3-second tick.

5. Unmount / Cleanup Resilience:
   - ALWAYS clear any active `setInterval` and `setTimeout` in `useEffect` cleanup
     or `componentWillUnmount` to prevent memory leaks or background network requests
     when the user navigates away or closes the modal.

8. PRODUCTION-GRADE REACT NATIVE / TYPESCRIPT REFERENCE COMPONENT
--------------------------------------------------------------------------------

```typescript
import React, { useState, useEffect, useRef } from 'react';
import {
  View,
  Text,
  TextInput,
  TouchableOpacity,
  ActivityIndicator,
  Alert,
  AppState,
  AppStateStatus,
  StyleSheet,
} from 'react-native';

interface PayAdProps {
  adId: string;
  adTitle?: string;
  amount?: number;
  token: string;
  onPaymentSuccess: () => void;
  onClose: () => void;
}

export const AfriMoneyAdPayModal: React.FC<PayAdProps> = ({
  adId,
  adTitle,
  amount,
  token,
  onPaymentSuccess,
  onClose,
}) => {
  const [phone, setPhone] = useState('');
  const [loading, setLoading] = useState(false);
  const [waitingPin, setWaitingPin] = useState(false);
  const [checkingStatus, setCheckingStatus] = useState(false);
  const [errorMsg, setErrorMsg] = useState('');

  const pollTimerRef = useRef<NodeJS.Timeout | null>(null);
  const maxTimeoutRef = useRef<NodeJS.Timeout | null>(null);

  const cleanupTimers = () => {
    if (pollTimerRef.current) {
      clearInterval(pollTimerRef.current);
      pollTimerRef.current = null;
    }
    if (maxTimeoutRef.current) {
      clearTimeout(maxTimeoutRef.current);
      maxTimeoutRef.current = null;
    }
  };

  // Listen for AppState changes: when returning from USSD PIN prompt overlay, check status instantly
  useEffect(() => {
    const handleAppStateChange = (nextAppState: AppStateStatus) => {
      if (nextAppState === 'active' && waitingPin) {
        pollStatus(true);
      }
    };

    const sub = AppState.addEventListener('change', handleAppStateChange);
    return () => {
      sub.remove();
      cleanupTimers();
    };
  }, [waitingPin]);

  const pollStatus = async (silent = false) => {
    if (!silent) setCheckingStatus(true);
    try {
      const res = await fetch(
        `https://www.meeemsl.com/mobileapi/seller/ads/${adId}/pay-afrimoney`,
        {
          method: 'GET',
          headers: {
            Authorization: `Bearer ${token}`,
            'Content-Type': 'application/json',
          },
        }
      );

      const data = await res.json();
      if (!silent) setCheckingStatus(false);

      if (data.paid || data.paymentStatus === 'COMPLETED') {
        cleanupTimers();
        setWaitingPin(false);
        Alert.alert(
          'Payment Successful!',
          'Your AfriMoney transaction was verified and your ad campaign is activated.',
          [{ text: 'Done', onPress: () => { onPaymentSuccess(); onClose(); } }]
        );
      } else if (data.paymentStatus === 'FAILED') {
        cleanupTimers();
        setWaitingPin(false);
        setErrorMsg('Payment authorization was declined or timed out. Please try again.');
      }
    } catch (e) {
      if (!silent) setCheckingStatus(false);
      // Network hiccup during polling: keep polling until timeout
    }
  };

  const handleInitiate = async () => {
    const cleanPhone = phone.trim();
    if (!cleanPhone) {
      setErrorMsg('Please enter your Africell mobile number (e.g. 080612072)');
      return;
    }

    setErrorMsg('');
    setLoading(true);

    try {
      const res = await fetch(
        `https://www.meeemsl.com/mobileapi/seller/ads/${adId}/pay-afrimoney`,
        {
          method: 'POST',
          headers: {
            Authorization: `Bearer ${token}`,
            'Content-Type': 'application/json',
          },
          body: JSON.stringify({ phone: cleanPhone }),
        }
      );

      const data = await res.json();
      setLoading(false);

      if (!res.ok || !data.success) {
        setErrorMsg(data.error || 'Failed to send USSD payment prompt.');
        return;
      }

      // If ad was already paid or budget is zero
      if (data.paid || data.paymentStatus === 'COMPLETED') {
        Alert.alert('Payment Completed', data.message || 'Ad is already paid.', [
          { text: 'OK', onPress: () => { onPaymentSuccess(); onClose(); } },
        ]);
        return;
      }

      // USSD sent successfully -> enter waiting state & start polling every 3 seconds
      setWaitingPin(true);
      cleanupTimers();

      pollTimerRef.current = setInterval(() => {
        pollStatus(true);
      }, 3000);

      maxTimeoutRef.current = setTimeout(() => {
        cleanupTimers();
      }, 90000); // 90 seconds timeout
    } catch (err: any) {
      setLoading(false);
      setErrorMsg(err.message || 'Network error connecting to payment gateway.');
    }
  };

  return (
    <View style={styles.container}>
      {/* Header Info */}
      <Text style={styles.title}>AfriMoney Push USSD Payment</Text>
      {adTitle ? <Text style={styles.adTitle}>Ad: "{adTitle}"</Text> : null}
      {amount !== undefined && amount !== null ? (
        <View style={styles.amountBox}>
          <Text style={styles.amountLabel}>Total Payable Amount:</Text>
          <Text style={styles.amountValue}>SLE {amount.toFixed(2)}</Text>
        </View>
      ) : null}

      {waitingPin ? (
        /* View 2: Waiting for PIN */
        <View style={styles.waitingContainer}>
          <ActivityIndicator size="large" color="#ea580c" />
          <Text style={styles.waitingTitle}>USSD Prompt Sent!</Text>
          <Text style={styles.waitingText}>
            Please check your phone screen ({phone}) and enter your AfriMoney PIN to confirm payment.
          </Text>

          <TouchableOpacity
            onPress={() => pollStatus(false)}
            disabled={checkingStatus}
            style={styles.checkButton}
          >
            {checkingStatus ? (
              <ActivityIndicator size="small" color="#fff" />
            ) : (
              <Text style={styles.checkButtonText}>Check Status Now</Text>
            )}
          </TouchableOpacity>

          <TouchableOpacity
            onPress={() => {
              cleanupTimers();
              setWaitingPin(false);
            }}
            style={styles.retryLink}
          >
            <Text style={styles.retryLinkText}>Change Number / Send Again</Text>
          </TouchableOpacity>
        </View>
      ) : (
        /* View 1: Phone Input */
        <View>
          <Text style={styles.inputLabel}>Africell Mobile Number:</Text>
          <TextInput
            placeholder="e.g. 080612072 or 033600171"
            value={phone}
            onChangeText={(txt) => {
              setPhone(txt);
              if (errorMsg) setErrorMsg('');
            }}
            keyboardType="phone-pad"
            style={styles.input}
            editable={!loading}
          />

          {errorMsg ? <Text style={styles.errorText}>{errorMsg}</Text> : null}

          <TouchableOpacity
            onPress={handleInitiate}
            disabled={loading || !phone.trim()}
            style={[styles.payButton, (loading || !phone.trim()) && styles.disabledButton]}
          >
            {loading ? (
              <ActivityIndicator size="small" color="#fff" />
            ) : (
              <Text style={styles.payButtonText}>Send USSD Payment Prompt</Text>
            )}
          </TouchableOpacity>

          <TouchableOpacity onPress={onClose} style={styles.cancelButton}>
            <Text style={styles.cancelButtonText}>Cancel</Text>
          </TouchableOpacity>
        </View>
      )}
    </View>
  );
};

const styles = StyleSheet.create({
  container: { padding: 20, backgroundColor: '#fff', borderRadius: 12 },
  title: { fontSize: 18, fontWeight: '700', color: '#111', marginBottom: 4 },
  adTitle: { fontSize: 13, color: '#666', marginBottom: 12 },
  amountBox: {
    flexDirection: 'row',
    justifyContent: 'space-between',
    alignItems: 'center',
    backgroundColor: '#ecfdf5',
    padding: 12,
    borderRadius: 8,
    marginBottom: 16,
    borderWidth: 1,
    borderColor: '#a7f3d0',
  },
  amountLabel: { fontSize: 13, fontWeight: '600', color: '#065f46' },
  amountValue: { fontSize: 16, fontWeight: '800', color: '#059669' },
  inputLabel: { fontSize: 13, fontWeight: '600', color: '#374151', marginBottom: 6 },
  input: {
    borderWidth: 1,
    borderColor: '#d1d5db',
```
